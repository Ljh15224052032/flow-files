# Tauri implementation

这里保存 Flow Files 的 Tauri 实现。主应用位于 [`app/`](app/)，它是当前持续维护的产品代码；目录名称保留 `tauri-prototype` 只是为了不破坏早期实验路径和桌面快捷方式。

项目技术栈：

- Tauri 2
- React 19
- TypeScript
- Rust stable / MSVC
- Windows API 与 WebView2

构建、测试、功能状态和版本规则统一记录在仓库根目录的 [README](../README.md)、[CHANGELOG](../CHANGELOG.md) 和 [ROADMAP](../ROADMAP.md) 中，避免多个文档出现互相矛盾的功能清单。

本目录不再单独维护另一份完整功能列表。
